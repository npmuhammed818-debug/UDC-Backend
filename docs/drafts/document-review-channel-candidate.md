## Deterministic document comparison
Accessible approved document extractions can be compared with recorded quantity, unit, unit price, currency, Incoterm and destination. Exact decimal strings avoid float rounding. Different units, price bases or currencies are not converted. Missing fields are not comparable. Stale/missing extraction returns 409. No model inference or paid API call is made by this check; results are flags for human review, never authenticity, banking or payment approval. Native SQL/HTTP checks executed for authorized mismatch, ungranted seller 404, stale extraction 409. Pure tests cover large decimals and unsupported conversions.
